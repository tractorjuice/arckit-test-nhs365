# NHS 365

Project ID: 001
Created: 2026-08-19

## Overview

Governance artifacts for NHS 365 — the adoption of Microsoft 365, Copilot, and
related AI capabilities across NHS organisations, derived from the source book
*NHS 365 — A Best Practices Guide for Transforming UK Healthcare with Microsoft AI*
(365apps.pro, 2026-08-11), held in `projects/000-global/external/`.

Cross-project architecture principles live in `projects/000-global/ARC-000-PRIN-v1.0.md`.

## Scope

The five chapters of the source book bound this project:

1. NHS England's Copilot rollout to 500,000+ staff
2. Strategic architecture and functional deployment of Microsoft 365 within the NHS
3. NHS workforce transformation and microlearning
4. Microsoft Teams Rooms in healthcare
5. Evolution of the NHS Care Identity Service (CIS2)
